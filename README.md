# Todo App

## Description
A simple and interactive Todo App built with **HTML, CSS, and JavaScript**.  
Users can **add tasks**, **delete tasks**, and enjoy a **clean, modern UI** with Google Fonts and Font Awesome icons.

## Features
- Add tasks dynamically
- Delete tasks using a trash icon
- Responsive layout for different screen sizes
- Modern design with colored container, shadows, and hover effects

## Tech Stack
- HTML
- CSS
- JavaScript
- Google Fonts (Poppins)
- Font Awesome icons
